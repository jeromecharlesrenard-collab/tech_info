### App Description \& Operation:

1. The website is a home page (index.html, "TECH INFO") with an alphabetical list of tech pages: Fabrication, Machinery \& Equipment, Materials, Polymer \& 3D Print.
2. Same site, style, script, tools, and conventions as the JCR Knowledge Bank (knowledge\_bank): shared style (assets/kb\_style.css), return and top arrows, search box, expand boxes, recap "R" buttons.
3. TECH INFO ADD: add a source file, text, or instructions to a page (or create a new page); Claude lays it out in the page style, checks it, and publishes it.
4. TECH INFO L: local preview (GitHub-like server). TECH INFO W: live site. TECH INFO PREVIEW: control window (OPEN SITE / CHECK SITE / EXIT).
5. Publish: commit and push to origin main; the live site updates in 1-2 minutes.
