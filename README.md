# tech_info
Tech Info

A collection of tech reference pages (machinery, materials, fabrication, 3D printing), published at
https://jeromecharlesrenard-collab.github.io/tech_info/

- `index.html` - home page with an alphabetical list of all pages
- `html_pages/` - all other pages
- `assets/kb_style.css` - shared style used by every page
- `templates/page_template.html` - starting point for new pages
- `tools/` - Python helpers to create pages, add data, check links, and preview locally
